# Жүйеге қойылатын талаптар

## Жоба сипаттамасы
Жеткізу жүйесі: тапсырыстарды қабылдау, курьерге тағайындау, жеткізу барысын бақылау және жеткізу тарихын сақтау үшін арналған.

## Функционалдық талаптар
1. Клиент жүйеде тіркеліп, жеке кабинетке кіре алады.
2. Клиент жеткізуге тапсырыс бере алады (мекенжай, байланыс телефоны, тауар сипаттамасы).
3. Клиент тапсырыс мәртебесін көре алады (қабылданды, жолда, жеткізілді).
4. Әкімші барлық тапсырыстар тізімін көре алады.
5. Әкімші тапсырысты курьерге тағайындай алады.
6. Курьер өзіне тағайындалған тапсырыстарды көріп, мәртебесін жаңарта алады.
7. Жүйе жеткізу тарихын сақтайды.

## Функционалдық емес талаптар
1. Деректер дерекқорда сақталады.
2. Жүйе интерфейсі қарапайым әрі қолдануға ыңғайлы болуы керек.
3. Қолданушы деректері рұқсатсыз қолжетімсіз болуы керек.
4. Жүйе сұранысқа 3 секундтан аз уақытта жауап беруі керек.
