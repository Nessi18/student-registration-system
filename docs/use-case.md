# Қолдану сценарийлері (Use Cases)

## Актерлер
- **Клиент:** жеткізуге тапсырыс беретін қолданушы.
- **Курьер:** тапсырысты жеткізетін қызметкер.
- **Әкімші:** тапсырыстар мен курьерлерді басқаратын қолданушы.

## UC1: Тапсырыс беру
- **Актер:** Клиент
- **Сипаттама:** Клиент тапсырыс формасын толтырып, жеткізу мекенжайы мен байланыс телефонын көрсетіп, тапсырысты жібереді.
- **Нәтиже:** Тапсырыс жүйеде тіркеліп, "Қабылданды" мәртебесін алады.

## UC2: Тапсырысты курьерге тағайындау
- **Актер:** Әкімші
- **Сипаттама:** Әкімші жаңа тапсырыстар тізімінен тапсырысты таңдап, бос курьерді тағайындайды.
- **Нәтиже:** Тапсырыс курьерге беріледі, мәртебесі "Жолда" болады.

## UC3: Жеткізу мәртебесін жаңарту
- **Актер:** Курьер
- **Сипаттама:** Курьер тапсырысты клиентке жеткізген соң, мәртебесін "Жеткізілді" деп белгілейді.
- **Нәтиже:** Клиент жаңартылған мәртебені көреді, тапсырыс жеткізу тарихына түседі.
